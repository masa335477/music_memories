## アプリ名： Music Memories

## 1. サービス概要
このアプリは、各々の好きな音楽への情熱を他人に共有するための音楽特化型SNSである。まだ自分の知らない楽曲に出会うことができるかも。

## 2. このアイデアはどこから生まれたか
音楽を聴くときに、自分が好きな楽曲を友達や恋人・職場の同僚にも紹介できるようにし、その楽曲の良さを分かち合いたいと思って作ろうとした。

### きっかけとなった体験・感情
音楽を聴いている中で、ただ自分が聴いて終わりではなく、その曲に対する思いを残すことができたらと思ったから。また、他人が自分の好きな曲に対して、コメントを残して分かち合うことができたならと思っている。

### なぜそれが「気になった」のか
- 自分の性格
自分はもともと音楽を聴くことが大好きである。毎日家でもスマホで音楽を聴くし、通勤する時も車でCDをかけるのが当たり前である。
- 過去の経験
自分の好きな楽曲を他人にもっと聴いてもらえるきっかけを作ることができたならと思った。
音楽鑑賞アプリ（SpotifyやApple Music等）では、楽曲を聴くことに特化しているため、コメントを残すことはどうしても重視していない印象があった。
そこで、一つのアプリで音楽を聴く（音楽アプリと連携）ことも、コメントやいいねもできるコミュニティを作りたいと考えた。

## 3. 課題の整理

### 表に見えている困りごと
既存SNSでは、音楽以外の話題も表示されること。


### 本当に解決したい課題
他の話題に振り回されない、音楽に特化したサービスを作りたい。
他人の好みを重宝しつつ、自分の好みも大切にしたい。


## 4. 想定ユーザーについて

### どんなユーザーを想定しているか
- サブスクで音楽を聴くユーザー
近年サブスクリプション（以下サブスク）で音楽を聴くのが当たり前になっている。通勤通学や車の運転など、日常のあらゆるシーンでサブスクが役立てられている。

- もっと好みを深めたい・広げたいユーザー

### 実際に使われる可能性について(需要・存在意義)
- 需要
近年XをはじめとするSNSを通じて好きな音楽やコンサートについてテキストで熱弁するユーザーが増加している。しかし、既存の総合SNS（特にX）は日常の雑多な話題も多く表示ため、「音楽の話題だけを見たい・盛り上がりたい」「熱量の高いレポだけを読みたい」という音楽ファンの需要を完全に満たしているとは言えない。また、音楽の投稿が他の話題に埋もれてしまう点もある。

- 存在意義
本サービスは、「音楽関連の思い出」のみ投稿可能となっている。
雑多な話題をタイムラインから排除するため、ユーザーは本当に興味のある音楽の話題だけに集中でき、熱量のあるコメントを通じて、既存のSNSおよびAIからのおすすめでは出会うことがなかった「新たな音楽の好み」を提供する。

### ユーザーがサービスを導入して利用するまでのイメージ(導入・継続の流れ)
ある音楽を聴くことが大好きなユーザーがいるとする。そのユーザーはある歌手の楽曲をよく聴いている。しかし、ある時楽曲の魅力やライブの感想を探すのに時間がかかっている。するとユーザーは音楽の投稿だけを読めるようなアプリがあったらと考える。そこで、そのユーザーが本アプリを導入（インストール）する。そして楽曲の魅力について説明文を書く。すると、他のユーザーから何件もの共感コメントがもらえた。すると、これなら音楽好きなユーザーと音楽のことだけで話し合えると思い、使い続けたいと考えた。

## 5. 既存サービス・競合調査

### 類似サービスの調査
- サービス名:Melolog（68期生 hinataさん制作）
- URL1:https://melolog.onrender.com/
- URL2:https://github.com/hinata7777/melolog
- どんなことができるのか:（ご本人のポートフォリオページの概要より）Melologは、音楽とともにその瞬間の思い出や好きなポイントを記録・共有できるサービスです。

### それでも自分が作りたい理由
上記の機能に加え、返信コメントや曲の好き度、AIによるおすすめ機能を実装したいと考えた。さらに、楽曲の投稿のみならず、（類似サービスには現状無い）アルバムに関する投稿も実装したいと考えている。そのほか、ランキング形式での投稿（お題を決めて、1位2位3位etcという形式で複数の曲を投稿）もできるようにしたい。


### 差別化を「体験価値」で表現すると
個々の楽曲はもちろん、アルバムについて投稿することも可能です。

## 6. このサービスで提供したい価値

### ユーザーの変化
ユーザーが音楽を聴くことだけでなく、他の人にその人が好きな曲を勧めたいと思うようになる。

### 価値を一文で表すと
あなたがまだ知らない音楽が出会えるかもしれない良い機会になるであろう。

## 7. このアプリで実装すること

### MVPで作る機能
楽曲・文章の投稿
投稿詳細ページ（表示・編集・削除）
コメント機能
タグ機能・タグ任意作成
いいね機能
Spotify検索・試聴機能（Spotify Web API）

### 本リリースで実装予定の機能
タグ自動作成

おすすめアーティストの紹介
→その楽曲やアーティストが好きあるいは楽曲を投稿した場合に他のおすすめを紹介する機能。おすすめポイント・特徴も添えて（アーティスト名横の"+ボタン"で表示）
例えばミスターチルドレンが好き・投稿したなら、スピッツを勧められると想定する。その際に特徴（歌詞がいい、メロディがいい等簡潔な言葉ではなく、「スピッツの○○という点がミスチルにも通ずる」といった少し長めの文章で説明）を深く説明すること。

本日のおすすめ曲1曲ずつ（他人からのおすすめ、好みに基づくおすすめ）

アカウント作成時のチュートリアル

好きなアーティストの設定（アカウント作成時、プロフィール編集時）

自分の人生の音楽史
